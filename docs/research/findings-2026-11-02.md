## Differences that must not be flattened

### SDK requirements

The tracing guide specifies Projects Python >= 2.0.0; the consulted prompt
and hosted quickstarts require >= 2.3.0. The Python hosted quickstart
requires Python 3.13+, whereas the tracing guide starts at Python 3.10.
This is not a contradiction: these are different paths. The solution must
select a consistent set matching the APIs actually used.
Sources: [S02](sources.md#s02), [S04](sources.md#s04), [S18](sources.md#s18).

.NET source deployment in the hosted quickstart requires .NET 10 and
`Azure.AI.Projects` 2.1.0-beta.4. The requirement does not automatically
extend to every service client. Toolbox shows a coordinated set of
preview .NET packages. Sources: [S04](sources.md#s04), [S13](sources.md#s13).

### Identity and scope

A project role does not automatically grant access to downstream data.
A role at Agent scope does not imply isolation of every resource called.
An agent identity does not prove that the tool is enforcing user rights.
Sources: [S03](sources.md#s03), [S10](sources.md#s10), [S11](sources.md#s11).

### Monitoring and maturity

Do not conclude that "all AgentOps is preview" from the page banner alone.
Track explicitly marked items and verify the rest.
Similarly, A2A v1.0 GA on the hosted page does not certify GA for all
hosted features. Sources: [S03](sources.md#s03), [S19](sources.md#s19),
[S21](sources.md#s21).

## Initial direction

Lab proposal: start with an explicit Agent Framework workflow,
compare it with a single agent, and assess Foundry hosted agents as the target.
Custom MCP is introduced only if it demonstrates value as a capability,
authorization, and reuse boundary. It is not needed to call the system "multi-agent".

The decision remains subject to the
[technical spikes](../demo/validation-roadmap.md) and a jointly agreed
use case. No model, region, or language has been selected.
